# Skill: Media review

## Изображения / скриншоты

1. Открой файл из `inputs/` или публичный URL (браузер / local web_fetch allowlist).
2. Опиши только видимое: текст, CTA, иерархия, шаги.
3. Сохрани `evidence/YYYYMMDD-media-<slug>.md` с путём/URL и датой.
4. Видимый текст → `fact`; выводы о мотивации → `hypothesis`.

## Аудио / видео

В этом репозитории **нет** встроенного ASR/видео-пайплайна (см. `docs/LIMITATIONS.md`).

Допустимо:

- Пользователь кладёт **текстовую расшифровку** (с согласием, без ПДн) в `inputs/` — далее как документ.
- Таймкоды и цитаты только из предоставленного текста.

Нельзя:

- Выдумывать содержание недоступного медиа.
- Класть сырые записи с ПДн в git.
