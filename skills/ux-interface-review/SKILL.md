# Skill: UX interface review

1. Открой публичный URL (браузер MCP) или скриншот из `inputs/`.
2. Опиши только видимое: иерархия, CTA, шаги пути, текст ценности, трение.
3. Не додумывай бэкенд-метрики и «типичное поведение», если этого нет в кадре.
4. Сохрани `evidence/YYYYMMDD-ux-<slug>.md` со ссылкой/путём и датой.
5. Гипотезы о барьерах → claims type `hypothesis`; видимые тексты/элементы → `fact`.
