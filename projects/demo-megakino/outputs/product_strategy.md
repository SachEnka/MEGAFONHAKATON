# Продуктовая стратегия — МегаКино

**Выбор:** вариант C + элементы B (см. `options.md`, `state/decisions.md`).

## Аудитория и задача (JTBD)

**Primary:** абонент МегаФона, который уже платит или готов платить порядка цены **одного** онлайн-кинотеатра и хочет *возможность сменить каталог без оформления нескольких подписок*, оплачивая с баланса номера.

**Ситуация:** выбирает, какой сервис смотреть «этот сезон / этот тайтл», а не коллекционирует одновременный доступ ко всем платформам.

**Secondary (не primary в этом квартале):** охотники за максимальным числом одновременных каталогов — им продукт честно не подходит без допов.

## Альтернативы пользователя

1. Одна прямая подписка OTT (Кинопоиск / START / …).
2. Несколько отдельных подписок.
3. Пиратство / отложенный просмотр / ничего.
4. Другие операторские/бандловые пакеты (вне детального open-сравнения здесь).

МегаКино выигрывает, если понятны: цена ≈ одного сервиса (`C015`), опция смены, один счёт. Проигрывает, если кажется «все пять сразу», а оказывается иначе.

## Выбранное направление

1. **Сделать механику «один активный» first-class в продукте и онбординге:** статус активного кинотеатра, сколько бесплатных переключений осталось, что будет после лимита — **до** и сразу после подключения.
2. **Упростить смену:** короткий путь из приложения/ЛК; объяснить лимит без «штрафного» сюрприза.
3. **Развести основные и допы:** допы не в первом экране ценности; явный ярлык «за доп. плату».
4. **Не менять** базовую модель «один активный из пяти» — она и есть продукт (`C003`, `C008`).

## Осознанные отказы

- Не обещаем и не строим UX «одновременный доступ ко всем пяти основным».
- Не делаем частый свитчинг главным сценарием (лимиты уже сигналят об этом — `C004`).
- Не масштабируем коммуникацию «широты рынка 2023» как текущий факт (`C009`).
- Не опираемся на демо-CSV отзывов как на KPI продукта (`C012`).

## Ценность, затраты, доходы

| | Логика на open data |
|--|---------------------|
| Ценность | Цена одного (~399 ₽) при опции выбора среди пяти основных |
| Затраты пользователя | Подписка + возможные платы за переключения сверх лимита + опциональные допы |
| Доходы оператора | Подписка 399 ₽ / 30 дней + switch fees + допы (доли неизвестны) |
| Пробел | Маржа, CAC, LTV, cannibalization прямых OTT — нет в open data |

Ставка квартала: **качественные** подключения с меньшим expectation gap важнее сырого top-of-funnel на двусмысленном оффере.

## Риски и допущения

- `C010–C011` — что барьер понимания материален (нужен тест).
- `C013` — что primary JTBD = сезонный выбор (синтетика).
- Риск: честное сообщение снизит клики — принять и мерить (`validation_plan.md`).

## Связь с коммуникацией (что можно обещать)

Можно: «Как за один кинотеатр — выбираете, какой из пяти активен»; «Сменить можно; N бесплатных раз в 30 дней»; «Только для абонентов МегаФона»; список пяти; допы отдельно.

Нельзя: «Смотрите все пять одновременно»; «Все каталоги рынка в одной кнопке без условий»; обещать состав 2023.
