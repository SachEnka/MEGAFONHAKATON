# Коммуникационная стратегия — МегаКино

Согласована с `product_strategy.md` (выбор C+B).

## Аудитория и ситуация

- **Кого:** абоненты МегаФона на этапе выбора развлечений / сравнения с одной OTT-подпиской.
- **Когда:** лендинг услуги, карточка в приложении, объяснение в поддержке, короткое промо в каналах оператора.
- **Состояние:** часто уже знакомы с одним кинотеатром; сравнивают «ещё одна подписка» vs «операторский пакет».

## Барьер понимания или выбора

1. **Понимание:** «5 кинотеатров» читается как одновременный доступ (`C010`, UX evidence).
2. **Выбор:** неясно, зачем пакет, если нужен один тайтл в одном сервисе — нужна рамка «сезонный выбор + право смены».
3. **Доверие:** допы и лимиты переключения, узнанные поздно, бьют по бренду оператора.

## Ключевое сообщение

**«Платите как за один кинотеатр — выбираете, какой из пяти активен. Сменить можно.»**

Подзаголовок (proof-ready): «START, Wink, КИОН, PREMIER или Кинопоиск — один активный в момент; 3 бесплатных переключения каждые 30 дней.»

## Подтверждение (proof)

| Утверждение | Proof |
|-------------|--------|
| Пять основных | Список на лендинге / инфосообщение — `C003`, `C006` |
| Цена как ориентир «за один» | 399 ₽ / 30 дней — `C015` |
| Не все сразу | FAQ + пресс-логика «один в моменте» — `C003`, `C008` |
| Лимиты переключения | FAQ — `C004` |
| Допы отдельно | FAQ — `C005` |

Визуальный proof: скрин статуса «сейчас активен: …» + остаток бесплатных смен (продуктовая зависимость).

## Роль каналов

| Канал | Роль | Сообщение / формат |
|-------|------|--------------------|
| Лендинг МегаКино | Главное объяснение механики | Новый hero + схема «1 активный»; FAQ без противоречия hero |
| Главная megafon.ru | Короткий якорь | Заменить двусмысленное «1 доступ — 5» на «1 активный из 5» |
| Приложение / ЛК | Онбординг и управление | Статус, лимиты, CTA «сменить кинотеатр» |
| Поддержка / суфлёр | Снятие претензий | Скрипт: что входит / что нет / как сменить |
| Performance / пуш | Трафик только с честным оффером | Не использовать «5 сразу» в креативе |
| PR | Осторожно | Не переиспользовать рыночные доли 2022/2023 как текущие |

## Чеклист согласованности с продуктом

- [x] Обещание «как за один» ↔ цена и модель одного активного
- [x] Обещание «из пяти» ↔ актуальный состав 2026
- [x] Обещание смены ↔ лимиты озвучены, не спрятаны
- [x] Допы не входят в ключевое сообщение первого экрана
- [x] Нет обещания одновременного доступа ко всем пяти

## Чего не говорим

- «Все кинотеатры сразу / без ограничений».
- «Больше половины рынка» без актуального открытого источника на текущий состав.
- «Бесплатно переключайтесь сколько угодно» (противоречит `C004`).
- Синтетические цитаты респондентов как «отзывы клиентов».
