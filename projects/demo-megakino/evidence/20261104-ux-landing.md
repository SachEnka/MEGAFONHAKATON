# UX-разбор публичного лендинга МегаКино

- Source: https://moscow.megafon.ru/services/megakino/
- Accessed: 2026-11-04
- Type: screenshot / page observation
- Method: skill ux-interface-review

## Видимое на странице

1. **Hero / первый экран:** акцент «5 кинотеатров по цене одного»; ограничение «только с номером МегаФона» рядом с оффером.
2. **Ценностные блоки:** «Один сервис — 5 кинотеатров», «Гибкое управление», каналы просмотра (браузер / приложение сервиса / Smart TV).
3. **FAQ ниже:** именно здесь раскрывается механика лимитов переключения (3 бесплатных / 30 дней, далее 30 ₽) и путь смены через ЛК.
4. **Список пяти основных + допов:** допы (Иви и др.) визуально/текстово соседствуют с основными — риск, что «пакет» читается шире оплаченного.

## Путь пользователя (по тексту страницы)

Узнать офер → понять ограничение оператора → подключить → управлять через ЛК/кнопку → выбрать/сменить кинотеатр → при желании докупить доп. каталог.

## Что **не** видно в материале

- Фактические шаги онбординга в приложении после оплаты.
- Метрики drop-off по шагам.
- A/B формулировок hero.

## Гипотезы (не факты)

- H1: Hero обещает «пять», FAQ объясняет «один активный» — барьер понимания возникает до FAQ.
- H2: Соседство допов с основными усиливает ожидание «всё включено».
