# Бриф (демо) — МегаКино

> Демонстрационный проект на **открытых данных**. Внутренней аналитики МегаФона нет.

## Размытый запрос руководителя продукта

«МегаКино вроде сильное предложение — пять кинотеатров по цене одного, — но ценность плохо считывается. Люди путают „пять сразу“ и „один активный с переключением“, жалуются на сложность, отваливаются или не подключают. Кому и как продавать? Что менять в продукте и что говорить аудитории? Нужна продуктовая и коммуникационная стратегия, которой можно доверять — с вариантами, а не с красивым текстом.»

## Уточнено на intake (зафиксировано агентом)

| Поле | Значение |
|------|----------|
| Решение | Выбрать продуктовую ставку МегаКино на 1–2 квартала и согласованную коммуникацию |
| Получатель | Руководитель цифрового продукта (развлечения / подписки) + соседний маркетинг |
| Ограничения | Только open data; без закрытых метрик удержания/воронки; срок «нужно вчера» → один проход с явной фиксацией пробелов |
| Доступные данные | Публичная страница услуги, инфосообщения абонентам, пресс-релиз, агрегированные публичные отзывы (демо-выборка), конкурентный срез цен OTT, UX публичного лендинга |
| Вне скоупа | Перепись партнёрских контрактов; изменение биллинга ядра тарифов; закрытые A/B МегаФона |

## Успех результата

1. Проверяемая картина ситуации (факты / гипотезы / пробелы).
2. ≥3 содержательно разных варианта, включая status quo и сужение/закрытие ставки.
3. Согласованные продуктовая + коммуникационная стратегии + план проверки.
4. Состояние на диске для продолжения после паузы.
