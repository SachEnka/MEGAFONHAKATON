# Routing — модель, инструмент, глубина

Цель: качество решения при меньшей полной стоимости (токены + повторы + время человека).

## Когда «быстрый» проход

- Классификация источника, извлечение цитат, черновик списка вопросов.
- Форматирование уже принятых решений.
- Проверка чеклиста артефактов.

## Когда «глубокий» проход

- Синтез situation и options.
- Финальные product + communication strategies.
- Steelman-возражения (или субагент `critic`).
- Пересмотр при конфликтующих новых данных.

## Когда субагент

См. [subagents.md](subagents.md). Правило: изолированная задача с чётким входом/выходом в файл, чтобы не раздувать основной контекст.

## Исправление ошибочного выбора

Если выбрал слишком мелкий инструмент (например, не хватило контекста сайта):

1. Запиши неудачу в ledger (`tool_failure`).
2. Переключись на более подходящий (браузер, другой skill).
3. Не дублируй уже сохранённые evidence без пометки «re-fetch».

## Стоимость

После глубоких шагов — `python tools/cost_log.py <id> --note "..."`.
