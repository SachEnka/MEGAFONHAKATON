# Intake — постановка задачи

## Цель

Сделать запрос исполнимым: вопрос, цель, получатель результата, ограничения, доступные данные.

## Спрашивай только блокирующее

Минимум для старта:

1. **Решение** — какое решение должен принять человек после твоей работы?
2. **Получатель** — кто читает итог (продакт, CPO, маркетинг)?
3. **Ограничения** — срок, бюджет, каналы, «нельзя трогать».
4. **Данные** — что уже есть (файлы, ссылки) и чего заведомо нет.

Не спрашивай предпочтения дизайна, «тон текста» и детали, которые не меняют исследование.

## Выход

Обнови `brief.md` (уточнённая версия) и `state/CURRENT.md`:

```markdown
## Phase
intake → gather

## Decision to support
...

...

...

...

...

## Blockers / questions for human
- (только если блокирует)
```
