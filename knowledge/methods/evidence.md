# Сбор материалов и атрибуция

## Разрешённые источники

- Открытые сайты и публичные страницы продуктов.
- Документы и таблицы, которые положил пользователь в `inputs/`.
- Публичные отзывы в агрегированном виде (без ПДн).
- Публичные скриншоты интерфейсов.

Запрещено: закрытые данные компаний, утечки, персональные данные без согласия.

## Формат evidence-файла

`evidence/YYYYMMDD-short-slug.md`:

```markdown
# Title
- Source: URL or path
- Accessed: YYYY-MM-DD
- Type: page | doc | table | review_aggregate | screenshot | other

## Extract
...

## Notes
Что следует / не следует из этого источника.
```

## Правила

- Одно существенное утверждение → один claim в `claims.jsonl` со ссылкой на evidence.
- При конфликте источников — оба в situation, не «усредняй молча».
- Сохраняй цитату или точную выдержку, не только интерпретацию.
