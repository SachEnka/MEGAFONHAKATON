# Факты, гипотезы, прогнозы

## Типы

| Тип | Значение | Пример |
|-----|----------|--------|
| `fact` | Проверяемое из источника «как есть» | «На странице МегаКино указано: 1 доступ — 5 онлайн-кинотеатров» |
| `hypothesis` | Объяснение или нужда, ещё не доказанная | «Пользователи не понимают, что входит в подписку» |
| `forecast` | Ожидаемый эффект при действии | «Упрощение оффера поднимет CTR лендинга на X» |

## Формат `claims.jsonl`

Одна строка = один JSON-объект:

```json
{"id":"C001","type":"fact","text":"...","source":"evidence/....md","confidence":"high|med|low","phase":"research"}
```

## Запреты

- Не повышай гипотезу до факта без нового источника.
- Синтетическое интервью → только `hypothesis`, поле `synthetic: true`.
- Ответ модели в чате без записи сюда не цитируй как доказательство в стратегии.
