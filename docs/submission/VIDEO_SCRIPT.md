# Сценарий видео ≤ 10 минут

Сквозной путь демо **МегаКино**. Запись: экран + голос.

| Мин | Что показать | Действие |
|-----|--------------|----------|
| 0:00–0:40 | Запрос | Открыть `brief.md`, прочитать размытый запрос |
| 0:40–2:30 | Работа агента | `python -m local_agent --check` → запуск / или Cursor resume; показать evidence + `claims.jsonl` |
| 2:30–4:00 | Исследование | `situation.md` / кусок `report.html` (факты vs гипотезы vs пробелы) |
| 4:00–5:30 | Варианты + gate | `options.md` A–D; сказать, что человек выбирает; показать зафиксированный C+B |
| 5:30–7:30 | Стратегия | product + communication + validation; согласованность обещаний |
| 7:30–8:30 | Пауза / новый чат | Новый чат: «Прочитай CURRENT.md — продолжай»; показать, что не с нуля (`PAUSE_CHECKPOINT_EXAMPLE.md`) |
| 8:30–9:30 | После решения | `decisions.md` + `revision_log.md` (новые данные не сбросили D1) |
| 9:30–10:00 | Запас / Ева 30с | Упомянуть вторую задачу `demo-eva` как proof обобщения |
