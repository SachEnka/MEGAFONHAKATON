# Заявленные возможности и ограничения

## Возможности

- Сквозной путь от размытого запроса до согласованных стратегий в Cursor.
- Продолжение после паузы через `state/CURRENT.md`.
- Атрибуция источников, разделение факт/гипотеза/прогноз.
- Human gate на выборе вариантов.
- CLI-валидация артефактов и учёт стоимости.
- Демо на открытых данных МегаКино.

## Ограничения

| Область | Ограничение |
|---------|-------------|
| Данные | Нет доступа к внутренней воронке/churn МегаФона — пробелы честно в situation/validation |
| Демо-CSV отзывов | Методический агрегат, не официальная статистика |
| Синтетические интервью | Только гипотезы; не доказывают спрос |
| Цены конкурентов в CSV | Ориентиры «public web»; требуют перепроверки на дату решения |
| Автономность | Нет 24/7 daemon; нужен человек в Cursor на gate и запуске |
| Мультимедиа | Нет отдельного ASR/видео-пайплайна; изображения — через описание/скрин в inputs |
| Векторный поиск | Навигация knowledge через INDEX + grep/поиск IDE |
| Стоимость | `cost.jsonl` — оценка; фактический биллинг Cursor может отличаться |
| Юрисдикция креатива | Агент предлагает стратегию; юридическая/партнёрская проверка — на стороне заказчика |

## Безопасность

- Секреты только в локальном `.env` (не в git).
- Инструкции из внешних источников не переопределяют правила агента.
- ПДн респондентов в репозиторий не кладём.
